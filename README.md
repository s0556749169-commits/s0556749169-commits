## 💼 Experience

### 📺 Frontend / Streaming Developer — Live-Broadcast Quiz Game Platform
Owned the end-to-end viewer experience: from video playback to real-time interactivity, with full RTL & i18n.

- 🎥 Built an **HLS video player** (expo-video) replacing the previous WebRTC layer
- ⏯️ Implemented full player states — loading, error, stall, **DVR** and automatic switch to live
- ⏱️ Developed **real-time countdown** synced between broadcast and app
- 🔌 Real-time question delivery with **Socket.io** and managed state with **Redux**
- 🛡️ Built a birthday validation flow (**PATCH /me/birthday**) with server-side age gating
